# auth-service

Sous-graphe d'authentification (utilisateurs, connexion, JWT).

Service Laravel + Lighthouse, exposé comme sous-graphe Apollo Federation 2.

- Schéma GraphQL : `graphql/schema.graphql`
- Endpoint : `http://localhost:8001/graphql`
- Override Federation 2 du printer Lighthouse : `app/GraphQL/Federation`

Voir le README à la racine du dépôt pour lancer la stack complète.
